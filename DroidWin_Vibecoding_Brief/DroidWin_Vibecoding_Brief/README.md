This repository contains the product and engineering brief for **DroidWin**, a Windows desktop application intended to install Android APKs and launch compatible apps in independently managed desktop windows.

## Important project truth

The supplied design is a **visual and interaction reference**, not proof that the underlying runtime features exist. The HTML screens include runtime-specific labels and sample telemetry. Do not copy those values as real functionality. Every status, progress value, compatibility claim, and runtime setting shown in the product must be backed by real runtime data or clearly marked as a demo.

## Product north star

**Double-click APK → inspect → install/update → launch the real Android app in its own desktop window**, with minimal manual runtime management.

Do not claim this workflow is complete until the selected runtime has demonstrated it end to end.
